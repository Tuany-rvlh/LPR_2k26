# 👨‍💻 Sobre o repositório

Este repositório foi criado como parte das atividades da disciplina de **Linguagem de Programação (LPR)**, do curso de **Desenvolvimento de Sistemas (DS)** da **ETE FMC**, ministrada pelo professor **José Andery**.

Este projeto representa meu primeiro contato com **Git e GitHub**, sendo utilizado como uma ferramenta de aprendizado, organização e evolução dos meus estudos em programação.

Aqui estão reunidos todos os exercícios desenvolvidos durante as aulas, implementados em **duas linguagens de programação diferentes**:

- 💙 **C++** — explorando conceitos fundamentais da programação estruturada;
- 💜 **C# (.NET)** — aplicando os mesmos conceitos utilizando a plataforma .NET.

O objetivo é desenvolver a lógica de programação e compreender como diferentes linguagens podem solucionar os mesmos problemas utilizando estruturas e sintaxes próprias.

# 📁 Estrutura do repositório

Os exercícios estão organizados por aula.  
Cada aula possui duas pastas principais, separando as implementações em **C++** e **C#**.

A mesma lógica de exercício é desenvolvida nas duas linguagens, permitindo comparar diferentes formas de implementação.

```
LPR_2k26/
│
├── AulaXX/
│   │
│   ├── C++/
│   │   └── exercicioYY.cpp
│   │
│   └── C#/
│       ├── Program.cs
│       └── exercicioYY.csproj
│
└── README.md
```

Exemplo:

```
Aula06/
│
├── C++/
│   ├── Ex01.cpp
│   ├── Ex02.cpp
│   └── Ex03.cpp
│
└── C#/
    ├── Ex01/
    │   └── Program.cs
    │
    ├── Ex02/
    │   └── Program.cs
    │
    └── Ex03/
        └── Program.cs
```

# ▶️ Como executar

## C++

1. Acesse a pasta do exercício em C++;
2. Compile o arquivo `.cpp`;
3. Execute o programa gerado.

Exemplo:

```bash
g++ exercicio.cpp -o programa
./programa
```

---

## C#

1. Acesse a pasta do exercício em C#;
2. Execute utilizando o .NET:

```bash
dotnet run
```
